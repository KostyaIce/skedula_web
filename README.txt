Skedula — сайт для GitHub Pages (обновление от 20.10.2026)

1. Создайте публичный репозиторий GitHub (например, skedula).
2. Загрузите СОДЕРЖИМОЕ папки skedula-site-updated в корень репозитория: index.html, support.html, privacy.html, style.css и папку assets. Не загружайте родительскую папку целиком.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. После публикации проверьте https://USERNAME.github.io/skedula/support.html и https://USERNAME.github.io/skedula/privacy.html.
5. Укажите эти URL в App Store Connect.

Перед публикацией проверьте точность политики: она основана на описанной разработчиком архитектуре. В частности, уточните состав синхронизируемых данных, использование фотографий, разрешения и поведение Yandex Login SDK.
