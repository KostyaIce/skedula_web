Информация об использовании данных в приложении Skedula.

Дата редакции: 20 октября 2026 года.

1. Общая информация

Skedula — приложение для ведения записей клиентов, личных дел, выходных, услуг и связанных рабочих сведений. Основные функции доступны без регистрации и подключения к интернету. Контакт по вопросам конфиденциальности: skedulaapp@mail.ru.

2. Данные, вводимые пользователем

Пользователь самостоятельно создаёт записи клиентов с датами, временем, описаниями и статусами (в том числе «Отменена»), добавляет контакты клиентов (имена, номера телефонов и другие введённые сведения), перечень услуг, личные дела, выходные, фотографии, сведения о стоимости услуг и доходах по записям, а также затраты на материалы, комплектующие и другие расходы. Эти данные используются для расписания, истории записей и статистики. При разрешённом импорте контактов сведения выбранных контактов переносятся из адресной книги устройства в приложение.

3. Локальное хранение

Рабочие данные сохраняются на устройстве пользователя. При отсутствии подключения к Яндекс.Диску синхронизация с этим сервисом не выполняется. Основные функции Skedula доступны офлайн.

4. Необязательная синхронизация с Яндекс.Диском

Пользователь может добровольно подключить личный Яндекс.Диск. После подключения Skedula автоматически синхронизирует изменённые данные при создании и редактировании записей, проверяет актуальность при запуске и позволяет запустить проверку вручную. Синхронизируются записи и их статусы, контакты, личные дела, выходные, услуги, финансовые сведения о доходах и расходах, а также фотографии. Передача выполняется напрямую на серверы Яндекса по HTTPS через REST API и Dart http, без промежуточного сервера разработчика. Данные сохраняются в выделенной папке приложения в личном Яндекс.Диске в виде читаемых JSON-файлов и изображений. Дополнительное шифрование содержимого средствами Skedula не применяется. Яндекс обрабатывает эти файлы согласно собственным условиям и политике конфиденциальности.

5. Авторизация Яндекса

На iOS подключение Яндекс.Диска выполняется через Yandex Login SDK с использованием OAuth. Авторизация и возможное дополнительное подтверждение личности происходят на стороне Яндекса. Skedula получает токен доступа для синхронизации, но не запрашивает пароль Яндекс ID. Обработка Яндексом сведений аккаунта и технических данных регулируется документами Яндекса; конкретные категории данных, собираемых SDK, зависят от его реализации и разрешений. Политика конфиденциальности Яндекса.

6. Получатели данных и цели

Сведения, вводимые в Skedula, используются для отображения расписания, ведения контактов, услуг и других выбранных пользователем функций. При включении синхронизации данные передаются Яндексу для хранения и обмена между устройствами пользователя. Разработчик не использует собственный сервер для хранения копий синхронизируемых записей и фотографий и не получает их напрямую через эту функцию. Обработка данных Яндексом регулируется его правилами.

7. Разрешения

При использовании соответствующих функций приложение может запрашивать доступ к контактам, фотографиям и уведомлениям. Разрешения предоставляются и изменяются пользователем средствами операционной системы.

8. Хранение, прекращение синхронизации и удаление

Записи, включая отменённые, сохраняются в локальной базе данных и используются для истории и статистики. Отмена записи изменяет её статус и не удаляет сведения. Локальные данные остаются в хранилище приложения; отдельная функция полного удаления данных в приложении не заявляется. Для удаления облачных файлов пользователь самостоятельно открывает Яндекс.Диск и удаляет содержимое выделенной папки Skedula. Удаление приложения с устройства не удаляет файлы с Яндекс.Диска. Если синхронизация продолжает работать на другом устройстве, облачные данные могут появиться снова. Для прекращения дальнейшей передачи в облако необходимо прекратить использование подключения к Яндекс.Диску и/или отозвать разрешение Skedula в настройках Яндекс ID; уже загруженные файлы удаляются отдельно в Яндекс.Диске. Удаление приложения с устройства обычно удаляет его локальное хранилище средствами операционной системы, но не гарантирует удаления ранее созданных резервных копий устройства. По вопросам обработки и удаления данных можно обратиться на skedulaapp@mail.ru. Разработчик не имеет прямого доступа к файлам в личном Яндекс.Диске пользователя и не может удалить их самостоятельно.

9. Обращения в поддержку

Если пользователь обращается по электронной почте, разработчик получает адрес отправителя и сведения, которые тот добровольно указывает в обращении, для ответа и решения вопроса. Не следует отправлять пароли, токены или файлы с персональными данными клиентов. Запросить уточнение или удаление сведений из переписки с поддержкой можно по адресу skedulaapp@mail.ru, с учётом применимых требований законодательства.

10. Безопасность

Передача данных в Яндекс.Диск осуществляется по HTTPS. Дополнительное сквозное шифрование JSON-файлов и изображений со стороны Skedula не применяется. За безопасность аккаунта Яндекса и доступ к файлам в нём также отвечают механизмы защиты соответствующего сервиса и настройки пользователя.

11. Изменения политики

При изменении функций приложения или способов обработки данных политика может обновляться. Актуальная редакция публикуется на этой странице.

12. Контакт

По вопросам конфиденциальности и поддержки: skedulaapp@mail.ru.
