Информация об использовании данных в приложении Skedula.

Дата редакции: 20 октября 2026 года.

1. О приложении

Skedula — приложение для планирования записей клиентов, личных дел, выходных, ведения списка услуг, учёта расходов и просмотра статистики. Основные функции работают без интернета и не требуют создания аккаунта Skedula.

2. Какие данные обрабатываются

Пользователь самостоятельно добавляет и изменяет данные, в том числе сведения о записях клиентов (например, дата, время, описание и выбранная услуга), личных делах и выходных, список клиентов и их контактные данные, перечень услуг, расходы и связанные с записями фотографии. Объём данных зависит от того, какие функции пользователь использует.

Если пользователь разрешает импорт контактов из адресной книги устройства, Skedula использует выбранные контактные сведения для добавления клиентов в приложение.

3. Хранение на устройстве

Рабочие данные сохраняются локально на устройстве. Пользователь может использовать основные функции Skedula без подключения к сети и без Яндекс ID.

4. Необязательная синхронизация через Яндекс.Диск

По желанию пользователь может подключить собственный Яндекс.Диск для резервного хранения и синхронизации данных между своими устройствами. При подключении приложение автоматически передаёт обновления при создании или изменении записей; при запуске проверяет актуальность данных коротким запросом. Также доступна ручная проверка синхронизации.

В облако могут передаваться записи клиентов, личные дела, выходные, контакты, услуги и связанные фотографии. Передача выполняется напрямую из Skedula на серверы Яндекса через HTTPS и REST API Яндекс.Диска, без промежуточного сервера разработчика. Данные сохраняются в выделенном каталоге приложения в личном Яндекс.Диске пользователя в виде читаемых JSON-файлов и изображений. Skedula не применяет к этим файлам дополнительное сквозное шифрование.

Хранение и обработка данных в Яндекс.Диске также регулируются условиями и политикой Яндекса: Политика конфиденциальности Яндекса.

5. Авторизация через Яндекс

Для подключения Яндекс.Диска используется Yandex Login SDK с авторизацией OAuth. Вход и возможная дополнительная проверка личности выполняются средствами Яндекса. Skedula получает токен доступа, необходимый для работы с Яндекс.Диском, но не запрашивает и не хранит пароль от Яндекс ID. Обработка технических данных при авторизации может осуществляться Яндексом в соответствии с его политикой.

6. Передача данных разработчику

Skedula не использует собственный сервер для хранения или синхронизации перечисленных пользовательских данных. Разработчик не получает копии файлов, синхронизируемых с личным Яндекс.Диском пользователя. При этом Яндекс как поставщик сервиса получает данные, необходимые для авторизации и облачного хранения.

7. Разрешения и уведомления

Для отдельных функций приложение может запрашивать доступ к контактам, фотографиям и разрешение на уведомления. Разрешениями можно управлять в настройках операционной системы. Функции, требующие соответствующего доступа, могут быть недоступны без разрешения.

8. Управление и удаление данных

Пользователь может изменять и удалять записи в приложении. Для удаления облачных файлов пользователь также может управлять содержимым выделенной папки Skedula в собственном Яндекс.Диске. Удаление приложения с устройства само по себе не гарантирует удаление ранее загруженных файлов из Яндекс.Диска.

9. Обращения в поддержку

При обращении по электронной почте разработчик получает адрес отправителя и сведения, добровольно включённые в сообщение, исключительно для рассмотрения обращения и ответа на него. Не отправляйте пароли, токены доступа и файлы с персональными данными без необходимости.

10. Обновление политики

Эта политика может обновляться при изменении функций Skedula или способов обработки данных. Актуальная версия публикуется на данной странице.
